# Big picture

The purpose of this branch is to ensure the agent operates within explicit boundaries before we add 
recovery, persistence, and human approval.

We'll guard four areas:

    Input
      ↓
    Execution limits
      ↓
    External research
      ↓
    LLM output

Specifically:

    Validate and normalize underwriting inputs.
    Enforce research limits from configuration.
    Prevent oversized queries/content from consuming resources.
    Validate LLM output before creating the final report.
    Ensure every insight references collected evidence.
    Prevent the LLM from inventing evidence IDs.
    Fail safely when the generated report is structurally invalid.

We should not implement prompt-injection defenses, sophisticated content moderation, or policy engines yet. Those are separate concerns we can add later without making this branch too large.

The key enterprise principle is:
