# Property Underwriting Intelligence Agent

An agentic AI research system that automates web-based property underwriting research.

How it works:

  Accepts an account, property address, and underwriting questions.
  Uses Tavily to discover relevant public web sources.
  Uses Firecrawl to extract and structure webpage content.
  Uses Azure OpenAI to synthesize the collected evidence.
  Produces a structured underwriting research report with findings, risk implications, confidence, evidence references, information gaps, and follow-up questions.
  Built with FastAPI + LangGraph, with configurable search and scraping limits.

In short:

Property details + underwriting questions → Web research → Evidence extraction → AI analysis → Evidence-backed underwriting insights.


It is a Research & Analysis Agent, more specifically an Agentic Web Intelligence Agent for Property Underwriting.

Its primary characteristics are:

Research Agent — searches external sources for relevant information.
Evidence-Gathering Agent — collects and extracts source material.
Analysis Agent — synthesizes evidence against underwriting questions.
Workflow/Orchestration Agent — uses LangGraph to coordinate the research steps.

So, the simplest professional description would be:

Agentic Web Research & Underwriting Intelligence Agent.
