
# Recommended architecture

For a checkpointed LangGraph application, I recommend:

Graph state should contain serialization-friendly primitive structures. Domain Pydantic models should be used at the application/service boundaries.

In other words:

    Domain models
        ↓
    convert to dict
        ↓
    LangGraph State
        ↓
    SQLite checkpoint
    
    and when needed:
    
    LangGraph State
        ↓
    dict
        ↓
    Pydantic domain model

This is cleaner for durable state and will also make PostgreSQL migration much easier later.
